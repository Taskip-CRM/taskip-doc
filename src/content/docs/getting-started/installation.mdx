# Installation

Taskip works in any browser, but also offers native apps for the best experience.

## Web App

No installation needed. Visit [taskip.net](https://taskip.net) and log in. The web app works on Chrome, Firefox, Safari, and Edge.

## Desktop App

<Tabs>
  <TabItem label="macOS">
    ```bash
    brew install --cask taskip
    ```
    Or [download the .dmg](https://taskip.net/download/mac) directly.
  </TabItem>
  <TabItem label="Windows">
    [Download the installer (.exe)](https://taskip.net/download/windows) and run it. Taskip will auto-update in the background.
  </TabItem>
  <TabItem label="Linux">
    ```bash
    # Debian/Ubuntu
    sudo apt install taskip
    
    # Or via AppImage
    chmod +x Taskip-*.AppImage && ./Taskip-*.AppImage
    ```
  </TabItem>
</Tabs>

## Mobile App

Download Taskip from the [App Store](https://apps.apple.com) or [Google Play](https://play.google.com). The mobile app supports offline mode — changes sync when you're back online.

<Aside type="caution">
  Mobile app requires Taskip version 2.0 or later. Update if you're on an older version.
</Aside>

## Self-Hosted (Enterprise)

Taskip Enterprise can be deployed on your own infrastructure using Docker.

```bash
docker pull taskip/server:latest
docker run -d \
  -e DATABASE_URL=postgres://... \
  -e SECRET_KEY=your-secret \
  -p 3000:3000 \
  taskip/server:latest
```

See the [full self-hosted guide](/guides/integrations/) for environment variables, reverse proxy setup, and backup configuration.
