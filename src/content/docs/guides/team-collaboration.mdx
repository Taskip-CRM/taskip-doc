# Team Collaboration

## Comments & Mentions

Every task has a comment thread. Open any task and scroll to the **Activity** section to post a comment.

### @Mentions

Type `@` followed by a teammate's name to mention them. They'll receive a notification immediately.

### Reactions

Hover over any comment and click the 😊 icon to react with an emoji. A quick way to acknowledge a message without cluttering the thread.

## Notifications

Taskip notifies you when:
- A task is assigned to you
- Someone mentions you in a comment
- A due date is approaching (24 hours before)
- A task you're watching changes status

### Notification Channels

Go to **Settings → Notifications** to choose how you get notified:
- **In-app** — Bell icon in the top nav
- **Email** — Summary emails (instant, daily, or weekly digest)
- **Slack** — Direct message or channel post (requires Slack integration)
- **Mobile push** — iOS and Android notifications

<Aside type="tip">
  Use **Watch** on any task to get notified of all activity, even if you're not assigned or mentioned.
</Aside>

## File Attachments

Attach files to any task by:
- Dragging and dropping into the task detail panel
- Clicking the **Attachment** button in the toolbar
- Pasting an image directly from your clipboard (`Cmd+V`)

Supported: images, PDFs, documents, archives. Max size: 50 MB per file.

## Guest Access

Invite external collaborators (clients, contractors) as **Guests**. Guests can only access projects they've been explicitly added to, and cannot see workspace-level settings.
