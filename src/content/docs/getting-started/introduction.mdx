# Welcome to Taskip

**Taskip** is a modern task and project management platform designed for teams that want to move fast without losing clarity. Whether you're a solo developer or managing a 50-person team, Taskip adapts to your workflow.

<Aside type="tip">
  New to Taskip? Start with the [Quick Start guide](/getting-started/quick-start/) to be up and running in under 5 minutes.
</Aside>

## Why Taskip?

Most project management tools are either too simple (sticky notes and spreadsheets) or too complex (enterprise platforms with steep learning curves). Taskip sits in the sweet spot — powerful enough for real teams, simple enough to start using today.

- **Fast by default** — Taskip loads instantly, even on slow connections
- **Keyboard-first** — Power users can navigate everything without a mouse
- **Real-time** — Changes sync instantly across all team members
- **Flexible** — Use it as a to-do list, a Kanban board, or a full project tracker

## Core Building Blocks

| Concept | What it is |
|---|---|
| **Task** | A unit of work with a title, description, assignee, and due date |
| **Project** | A collection of related tasks organized with a shared goal |
| **Board** | A visual Kanban-style view of tasks in a project |
| **Workspace** | Your organization's top-level container for all projects |
| **Member** | A user with a role (Owner, Admin, Member, or Viewer) |
