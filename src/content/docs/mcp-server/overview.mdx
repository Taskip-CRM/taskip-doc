Taskip runs a native **MCP (Model Context Protocol) server**, so AI assistants like Claude, Claude
Code, Claude Desktop, Cursor, VS Code, and ChatGPT can connect directly to your workspace. Instead
of copy-pasting data between Taskip and your AI assistant, your AI tools can look up clients,
create tasks, draft invoices, and manage projects on your behalf, right inside the conversation
you're already having.

[Model Context Protocol](https://modelcontextprotocol.io) is an open standard for connecting AI
assistants to real applications through a secure, standardized connection, instead of a
one-off integration per tool.

## How it connects

<McpArchitectureDiagram />

Each AI client you connect gets its **own unique secret** (or, for Claude's web app, its own
signed-in session), generated from **Settings → MCP Server** in your workspace, not a shared
password. You can revoke any single connection at any time without affecting the others. See
[Security & FAQ](/mcp-server/security-and-faq/) for details.

<Aside type="tip">
  Taskip also ships **[Taspi](/taspi-ai/overview/)**, a built-in AI agent inside your workspace.
  The MCP server is for connecting *external* AI tools you already use, they both work side by
  side.
</Aside>
