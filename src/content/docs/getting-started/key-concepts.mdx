# Key Concepts

Understanding a few core ideas will help you get the most out of Taskip.

## Workspace

A **Workspace** is the top-level container for your organization. Everything in Taskip lives inside a workspace — projects, members, settings, and billing.

You can be a member of multiple workspaces (e.g. your company and a side project). Switch between them using the workspace switcher in the top-left corner.

## Projects

A **Project** groups related tasks together around a shared goal. Examples:

- `Website Redesign`
- `Q2 Marketing Campaign`
- `Bug Tracker`

Each project has its own sidebar with views: **Board**, **List**, **Timeline**, and **Calendar**.

## Tasks

A **Task** is the core unit of work. Every task has:

| Field | Description |
|---|---|
| Title | What needs to be done |
| Assignee | Who is responsible |
| Due Date | When it's due |
| Priority | Urgent, High, Medium, Low, or None |
| Status | Todo, In Progress, In Review, Done |
| Labels | Custom tags for filtering |
| Description | Rich text notes, checklists, and attachments |

<Aside type="tip">
  Use **subtasks** to break a big task into smaller steps. Subtasks appear nested under the parent task in List view.
</Aside>

Taskip supports multiple views of the same data:

## Members & Roles

| Role | Permissions |
|---|---|
| **Owner** | Full access including billing and workspace deletion |
| **Admin** | Manage members, projects, and settings |
| **Member** | Create and edit tasks within projects they belong to |
| **Viewer** | Read-only access |
